# Archex GTM — Coming Soon Website

A single-page coming-soon experience for **Archex GTM**, designed as the forward-looking, experimental sibling of **Archex Studio**.

## Brand DNA & Visual Hierarchy

- **75–85% Shared DNA**: Inherits the warm paper (`#F2EFE8`), deep ink (`#141414`), graphite (`#5E5B55`), and signal red/coral (`#9C3E2F` / `#F27B61`) color tokens, along with identical typography: `DM Serif Display` and `Instrument Sans`.
- **GTM Kinetic Personality**: Introduces directional vectors, momentum paths, telemetry coordinates, connected launch nodes, and interactive pillar switching.
- **Specimen Card**: Authentic Archex family physical specimen card with 16px offset terracotta drop shadow, typography specimen, and live velocity bars.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS variables
- **Motion & Interactions**: Framer Motion / Motion for React with `prefers-reduced-motion` compliance
- **Typography**: Local `DM Serif Display` & `Instrument Sans` (`.woff2`)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Run production build
npm run build
npm run start
```
